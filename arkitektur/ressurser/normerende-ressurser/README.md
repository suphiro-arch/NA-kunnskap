# Standarder og veiledning

Denne tekniske mappa brukes for standarder og veiledning. Kategorien omfatter blant annet standarder, veiledere, referansearkitektur, informasjonsmodeller, begrepsmodeller og rammeverk som gir føringer for utforming, vurdering eller samordning.

Bruk [styringsregler.md](../styringsregler.md) før nye filer eller understrukturer opprettes her.

Foreløpig malgrunnlag for slike beskrivelser ligger i [normerende-ressurs-template.md](../../../config/templates/normerende-ressurs-template.md).

Naturlige kandidater i denne strukturen er blant annet:
- `FINT Informasjonsmodell`
- relevante standarder og veiledere
- referansearkitektur og andre semantiske eller styrende modeller
