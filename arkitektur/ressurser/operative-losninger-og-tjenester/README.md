# Gjenbrukbare løsninger

Denne tekniske mappa brukes for gjenbrukbare løsninger som skal beskrives videre under ressursområdet. Det omfatter blant annet tjenester, plattformer, registre, portaler, felleskomponenter og andre løsninger som kan brukes direkte i samhandling eller løsningsutvikling.

Bruk [styringsregler.md](../styringsregler.md) før nye filer eller understrukturer opprettes her.
