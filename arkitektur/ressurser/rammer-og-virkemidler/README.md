# Økonomiske og juridiske rammer og virkemidler

Denne mappa brukes for ressurser som primært setter juridiske, økonomiske eller styringsmessige rammer for digital samhandling.

Typiske kandidater er forskrifter, rundskriv, finansieringsordninger og andre virkemidler som påvirker handlingsrom, prioritering eller gjennomføringsevne. De fleste øvrige normerende ressurser ligger fortsatt i den tekniske mappa `normerende-ressurser/`.

Nye ressurser skal bare legges her når klassifiseringen er vurdert mot `arkitektur/ressurser/styringsregler.md`.
