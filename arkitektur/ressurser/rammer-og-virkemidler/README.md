# Økonomiske og juridiske rammer og virkemidler

Denne mappa er reservert for ressurser som primært setter juridiske, økonomiske eller styringsmessige rammer for digital samhandling.

Typiske kandidater kan være forskrifter, rundskriv, finansieringsordninger og andre virkemidler som påvirker handlingsrom, prioritering eller gjennomføringsevne. De fleste eksisterende normerende ressurser blir foreløpig liggende under `standarder-og-veiledning` via den tekniske mappa `normerende-ressurser/`.

Nye ressurser skal bare legges her når klassifiseringen er vurdert mot `arkitektur/ressurser/styringsregler.md`.
