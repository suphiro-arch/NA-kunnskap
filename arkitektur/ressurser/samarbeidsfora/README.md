# Samhandlingsarenaer og organisering

Denne tekniske mappa brukes for samhandlingsarenaer og organisering. Kategorien omfatter blant annet fora, råd, nettverk, åpne digitale samhandlingsarenaer, styringsarenaer og organiseringsformer som støtter koordinering, forankring, faglig dialog eller prioritering på tvers.

Bruk [styringsregler.md](../styringsregler.md) før nye filer eller understrukturer opprettes her.
